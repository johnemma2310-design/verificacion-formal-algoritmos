      Validación computacional
      
    
      Se ejecutan miles de casos aleatorios. En cada iteración se comprueba el invariante y que la variante decrezca; al final, la postcondición se compara contra un oráculo por fuerza bruta
      (recorrido lineal para la búsqueda; probar todos los divisores para el mcd). También se verifica la cota de iteraciones.
      
    
      
      
      
      
      
    
      
    
      
  
      

      



      
  
      
    
      Método: correctitud = correctitud parcial + terminación
      
    
      Para un ciclo mientras G hacer S con invariante I y función variante V (entera), se demuestra por inducción sobre el número de iteraciones k:
      
    
        
      
      1. Inicialización (caso base, k = 0): la precondición y las asignaciones iniciales implican I.
        2. 
      
      2. Mantenimiento (paso inductivo): si I ∧ G se cumplen antes de una iteración, I se cumple después.
        3. 
      
      3. Salida: I ∧ ¬G ⇒ postcondición.
        4. 
      
      4. Terminación: V ≥ 0 mientras G, y cada iteración la hace decrecer estrictamente. Como no existe una sucesión infinita estrictamente decreciente en ℕ (principio del buen orden), el ciclo termina.
        5. 
    
      
  
      

  
      
    
      Búsqueda binaria
      
    
      
      Pre: A[0..n−1] ordenado: A[0] ≤ A[1] ≤ … ≤ A[n−1]
      
      Post: (r ≠ −1 ∧ A[r] = x) ∨ (r = −1 ∧ x ∉ A)
      
      I: 0 ≤ lo ≤ hi+1 ≤ n ∧ (∀k < lo: A[k] < x) ∧ (∀k > hi: A[k] > x)
      
      V = hi − lo + 1
    
      
    
      Inicialización. lo = 0, hi = n−1: 0 ≤ 0 ≤ n ≤ n, y los conjuntos {k < 0} y {k > n−1} son vacíos, así que los cuantificadores son verdaderos por vacuidad.
      
    
      Mantenimiento. Supongamos I y lo ≤ hi; sea mid = ⌊(lo+hi)/2⌋, con lo ≤ mid ≤ hi.
      
    
        
      
      • Si A[mid] = x se retorna mid y la postcondición se cumple de inmediato.
        • 
      
      • Si A[mid] < x: por el orden, A[k] ≤ A[mid] < x para todo k ≤ mid; tras lo ← mid+1 se cumple ∀k < lo: A[k] < x. Lo demás no cambia.
        • 
      
      • Si A[mid] > x: simétrico, A[k] ≥ A[mid] > x para k ≥ mid, y hi ← mid−1.
        • 
    
      
    
      Salida. Si el ciclo termina sin retornar, lo = hi+1, de modo que todo índice k cumple k < lo o k > hi, y por I A[k] ≠ x. Entonces x ∉ A y retornar −1 es correcto.
      
    
      Terminación. En las dos ramas, V pasa a (mid − lo) o (hi − mid), ambas < hi − lo + 1. Además V ≥ 0 por I. Como V se reduce al menos a la mitad, hay como máximo ⌊log₂ n⌋ + 1 iteraciones.
      
    
      ¿Por qué falla la versión con error? Con lo ← mid el invariante se sigue cumpliendo, pero si hi = lo + 1 entonces mid = lo y V no cambia: la correctitud parcial no basta, hace falta la variante. El simulador lo detecta.
      
  
      

  
      
    
      Algoritmo de Euclides
      
    
      
      Pre: a₀, b₀ ∈ ℤ, a₀ ≥ 0, b₀ ≥ 0, no ambos 0
      
      Post: el valor retornado es mcd(a₀, b₀)
      
      I: a ≥ 0 ∧ b ≥ 0 ∧ mcd(a, b) = mcd(a₀, b₀)
      
      V = b
    
      
    
      Lema. Si a = q·b + r, entonces mcd(a, b) = mcd(b, r).
      
      Prueba: si d | a y d | b, entonces d | a − q·b = r. Recíprocamente, si d | b y d | r, entonces d | q·b + r = a. Los pares (a, b) y (b, r) tienen exactamente los mismos divisores comunes, así que su máximo coincide. ∎
      
    
      Inicialización. a = a₀, b = b₀: I se cumple trivialmente.
      
    
      Mantenimiento. Si b ≠ 0, r = a mod b cumple 0 ≤ r < b. Por el lema, mcd(b, r) = mcd(a, b) = mcd(a₀, b₀).
      
    
      Salida. Si b = 0, mcd(a, 0) = a, luego a = mcd(a₀, b₀).
      
    
      Terminación. V = b ≥ 0 y el nuevo b es r < b. Por el teorema de Lamé, el número de divisiones es como máximo 5 veces el número de dígitos de min(a₀, b₀); el peor caso son números de Fibonacci consecutivos.
      
    
      ¿Por qué falla la versión con error? Con r ← ⌊a/b⌋ el ciclo termina, pero el lema ya no aplica: el invariante se rompe (ej. 48, 18 → 18, 2 y mcd cambia de 6 a 2). Terminar no basta, hace falta el invariante.
